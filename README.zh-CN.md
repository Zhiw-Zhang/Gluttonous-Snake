# 基于 MSPM0G3519 的贪吃蛇

基于德州仪器 **MSPM0G3519** 微控制器实现的经典贪吃蛇游戏，配备 OLED 显示屏、4×4 矩阵键盘本地控制，并通过 **UART** 与 VOFA+ 实现远程控制，支持双控制方式同时操作，为大学生电子设计竞赛培训项目。

---

## 🎮 功能特性

- **完整的贪吃蛇游戏逻辑**：蛇的移动、食物消耗、身体增长、边界碰撞及计分。
- **OLED 图形显示**：通过 OLED 屏幕实时显示蛇、食物、游戏区域及界面。
- **双控制方式**：
  - **矩阵键盘**本地控制：方向键、暂停/继续、退出。
  - **UART 串口命令**（VOFA+）远程控制：开始、暂停、方向等命令。
- **食物机制**：食物随机生成；若在设定时间内未被吃掉，则重新生成，防止死局。
- **计分与惩罚**：每吃一个食物增加分数；碰到边界扣分（可配置）。
- **暂停/继续**：通过键盘或串口命令均可暂停/恢复游戏。
- **启动与菜单界面**：开机画面及开始游戏的简单选择界面。
- **软件消抖**：对键盘输入进行消抖处理，保证可靠检测。

## 🛠 硬件

| 组件 | 说明 |
|------|------|
| **MCU** | 德州仪器 MSPM0G3519 |
| **显示** | 128×64 OLED 屏幕 |
| **输入** | 4×4 矩阵键盘，占用 8 个 I/O 引脚 |
| **远程控制** | UART，用于与 VOFA+ 或串口工具通信 |

---

## 💻 软件架构

固件使用 **TI DriverLib** 和 SysConfig 编写，采用 C 语言。

### 主要模块

| 模块 | 说明 |
|------|------|
| `main.c` | 初始化、主循环、键盘 + UART 命令处理、屏幕状态机 |
| `Keyboard.c/h` | 矩阵键盘扫描及软件消抖，返回按下按键的 ASCII 字符 |
| `oled_spi_V0.2` | OLED 底层驱动：SPI 通信、像素绘制、字体、屏幕刷新 |
| `function.c/h` | 游戏核心逻辑：蛇移动、碰撞检测、计分、食物生成、定时 |
| `interface.c/h` | UI 界面（开机、暂停、结束画面）及菜单绘制 |

### UART 远程控制

- **波特率**：115200（可配置）
- **数据格式**：8N1
- **协议**：简单的单字节命令（ASCII 字符）
- **VOFA+ 配置**：创建按钮，将“发送内容”设置为对应 ASCII 字符（纯文本，无需额外帧头）

| 命令 | 对应按键 | 动作 |
|------|----------|------|
| `A` | `A`（键盘） | 开始游戏 |
| `#` | `#`（键盘） | 暂停/继续 |
| `*` | `*`（键盘） | 退出游戏 |
| `2` | `2`（键盘） | 向上移动 |
| `8` | `8`（键盘） | 向下移动 |
| `4` | `4`（键盘） | 向左移动 |
| `6` | `6`（键盘） | 向右移动 |

UART 接收中断将接收到的字节存入 `volatile` 变量，主循环同时检查该变量和键盘输入，确保两种控制方式同时有效。

## 🕹 使用方法

### 本地控制（矩阵键盘）

- **开始游戏**：按下 `A`
- **方向控制**：`2` 上、`8` 下、`4` 左、`6` 右
- **暂停/继续**：`#`
- **退出游戏**：`*`

### 远程控制（VOFA+）

1. 将 USB-TTL 适配器连接到电脑和开发板。
2. 打开 **VOFA+**，选择正确 COM 口，波特率设置为 115200。
3. 创建按钮并将“发送内容”设置为对应 ASCII 字符命令。
4. 点击按钮发送命令，游戏会立即响应。
